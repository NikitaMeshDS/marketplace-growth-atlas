## Атлас спроса

Индивидуальная работа для стипендиального конкурса «Система», номинация «Технологии электронной коммерции». Прототип помогает продавцу выбрать муниципалитеты для пробного продвижения и сравнить их по доставке, наличию товара и доступной зоне показов.

Я разработал метод отбора, провёл историческую проверку и собрал интерактивное демо. При пороге 2 000 ₽ на жителя сигнал роста нашёл 743 из 1 296 мест (57,3%) в фактических тройках по годовому процентному росту расходов на архивных данных 64 субъектов РФ.
